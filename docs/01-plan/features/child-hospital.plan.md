### Value Delivered

| 관점 | 설명 |
|------|------|
| **Problem** | 동대문구는 야간·휴일 소아 진료를 책임지는 달빛어린이병원이 **0개소**다. 인근 성북·성동·중랑구는 모두 1곳 이상 운영 중인데, 동대문 부모들만 밤마다 응급실 뺑뺑이를 돌고 있다. 핵심 타겟층인 3~40대 어린 자녀 가정이 매일 체감하는 문제이지만, 후보가 이 문제를 위해 무엇을 해왔는지 보여주는 페이지가 사이트 내에 없다. |
| **Solution** | 진보당 동대문구 지역위원회가 2월 추진본부 설립 → 4월 21일 **주민 3,025명 서명을 동대문구청에 전달**한 캠페인 전 과정을 타임라인·사진·기사 인용으로 보여주는 단일 페이지(`/child-hospital`)를 만든다. |
| **Function UX Effect** | 유권자는 한 페이지 안에서 "달빛어린이병원이 무엇인지 → 동대문구가 왜 0개인지 → 오준석 후보가 무엇을 해왔는지 → 앞으로 무엇을 하겠다는 것인지"를 1분 안에 파악한다. 서명 박스 전달 사진과 기자회견 사진이 결정적 증거(evidence)로 작용한다. |
| **Core Value** | "어린 자녀를 둔 같은 이웃이, 같은 문제를 풀기 위해 이미 행동했다" — 후보의 **공감대 + 실행력**을 동시에 증명한다. 감정이 아니라 사진·숫자·기사 인용이라는 사실로 신뢰를 만든다. |

## 1. 배경 및 목적

### 1.1 현재 상태
- **사이트 내 달빛어린이병원 콘텐츠 없음** — 후보의 가장 중요한 최근 활동이 사이트에 빠져 있음
- **footer 메뉴 "후보활동" (`/news`)**: 활동 목록만 있고 개별 캠페인 상세는 없음
- **자료 확보됨**:
  - `child_hospital/gallery_11.jpeg` — 오준석 후보가 "달빛어린이병원 설치! 3,025개의 주민서명 동대문구청전달" 박스를 동대문구청에 전달하는 장면 (결정적 한 컷)
  - `child_hospital/photo_2026-05-14 08.44.55.jpeg` — 거리 캠페인/피켓 사진 (※ 파일이 거꾸로 회전되어 있어 보정 필요)
  - NGO News 기사 (https://www.ngonews.kr/news/articleView.html?idxno=228739, 2026-04-21, 이영일 기자)

### 1.2 문제점
1. **핵심 타겟층 미스매치** — 3~40대 어린 자녀 가정이 매일 겪는 응급실 뺑뺑이 문제를 다룬 페이지가 없다
2. **활동 증명 부재** — 후보가 단순히 공약만 외치는 게 아니라 이미 3,025명 서명을 받아 행정에 압박을 가했다는 사실이 사이트에서 보이지 않음
3. **외부 기사 의존** — 기사를 읽지 않은 방문자에게는 이 활동이 존재하지 않는 것과 같음

### 1.3 목표
- 달빛어린이병원 캠페인 활동을 **단일 페이지에 종합 정리**
- **3,025**라는 숫자, **0개**라는 동대문구 현황을 시각적으로 강조
- 추진본부 설립(2월) → 서명운동 → 동대문구청 전달(4월 21일) **타임라인** 제시
- 향후 "구의회에서 무엇을 하겠다"는 **다음 단계 공약**으로 자연스럽게 이어짐
- SNS/카톡으로 공유했을 때 **OG 이미지가 결정적 한 컷(서명 박스 전달)** 으로 노출

## 3. 기능 요구사항

### FR-01: Hero 섹션
- 풀스크린 배경: `child_hospital/gallery_11.jpeg` (서명 박스 전달 장면)
- 어두운 그라데이션 오버레이 (`bg-gradient-to-b from-sky-900/70 to-sky-900/90`)
- 헤드라인: **"응급실 뺑뺑이 내몰린 아이들, 동대문구는 0개"** (font-black, 한글 줄바꿈 자연스럽게)
- 서브카피: "2026년, 어린 자녀를 둔 부모들이 직접 움직였습니다."
- 작은 캡션: "2026.04.21 · 동대문구청 앞 · 주민 3,025명 서명 전달"

### FR-02: 핵심 숫자 섹션
- 3개 카드 (모바일 1열, 데스크톱 3열):
  1. **3,025명** — 동대문구 주민 서명 수
  2. **0개소** — 동대문구 달빛어린이병원
  3. **121개소** — 전국 운영 달빛어린이병원
- 인근 자치구 비교(성북·성동·중랑) 작은 표 또는 캡션으로 추가

### FR-03: "달빛어린이병원이란?" 섹션
- 글래스모피즘 카드 1개 + Lucide 아이콘 (Stethoscope or Moon)
- 본문: 2-3 문단
  - 야간/휴일 소아 진료 공백 문제
  - 정부·지자체가 운영비 지원하면 동네 소아과가 밤 12시까지 진료 가능
  - 동대문구는 조례만 있고 참여 병원 없음

### FR-04: 추진 타임라인
- 세로 타임라인 (Vertical timeline) 또는 카드 스택
- 노드 3-4개:
  1. **2026.02** — 진보당 동대문구 지역위원회, **달빛어린이병원 추진본부 설립** (공동본부장: 김택연)
  2. **2026.02~04** — **주민 서명운동 전개** (피켓 거리 캠페인 사진 — photo_2026-05-14 회전 보정)
  3. **2026.04.21** — **동대문구청 앞 기자회견 + 3,025명 서명 전달** (gallery_11 사진)
  4. **다음 단계** — 구의원 당선 시 의회에서 추진 (CTA로 연결)
- 각 노드: 날짜 뱃지 + 제목 + 1-2 문장 설명 + (있다면) 작은 사진 썸네일

### FR-05: 후보 메시지 섹션 (기사 인용 대신 재작성)
- 형식: 후보 단독 메시지 카드 1개 (사진 + 짧은 본문 2-3 문단)
- 후보 톤으로 재작성:
  - "왜 동대문구에는 달빛어린이병원이 없을까" — 문제 인식
  - "왜 우리가 직접 움직였나" — 추진본부 결성 이유, 같은 부모의 마음
  - "구의회에 들어가면 무엇을 하겠다" — 다음 단계 약속
- 추진본부 다른 인물(박지하·김택연) 언급은 본문 내 자연스럽게 1회 정도
- 출처: 본문 하단에 작은 글씨로 "관련 기사: NGO News (2026-04-21) →" 외부 링크 1개만

### FR-06: 다음 단계 + CTA
- "오준석이 약속드립니다" 섹션:
  - 구의회 진입 시 — 참여 병원 발굴 / 재정 지원 확대 / 동대문구청 적극 행정 압박
  - 기사에 명시된 3가지 요구사항을 그대로 공약화
- CTA 버튼 2개:
  - **"의견 보내기"** → `/opinions` (기존 페이지)
  - **"응원하기"** → `/donate` 또는 메인 페이지 CTA

### FR-07: 공유 메타데이터 (OG)
- `metadata.openGraph.images`: gallery_11.jpeg
- `metadata.title`: "달빛어린이병원, 동대문에도 — 오준석"
- `metadata.description`: "주민 3,025명이 서명했습니다. 동대문 어린 자녀 가정을 위한 야간·휴일 소아 진료."

### FR-08: 네비게이션 통합
- `footer.tsx`의 `FOOTER_LINKS`에 **"달빛어린이병원"** 항목 추가 (`{ label: "달빛어린이병원", href: "/child-hospital" }`)
- 메인 페이지(`src/app/page.tsx` → 적절한 컴포넌트)에 **활동 카드 1장** 추가
  - 결정적 한 컷(gallery_11) + 헤드라인 "주민 3,025명과 함께한 달빛어린이병원 요구" + "자세히 보기 →" 링크
- 헤더(navbar)에는 추가하지 않음 (현재 헤더 메뉴 구성 유지)

## 4. 비기능 요구사항

| 항목 | 요구사항 |
|------|---------|
| **반응형** | 모바일 우선 (Hero 풀스크린 시 모바일에서 안전영역 확보, 핵심 숫자는 모바일 1열) |
| **터치 타겟** | 모든 버튼·링크 최소 44×44 px |
| **본문 가독성** | 본문 16px 이상, 줄간격 1.6 이상, 한글 줄바꿈 부자연스럽지 않게 |
| **이미지 최적화** | `next/image` 사용, gallery_11.jpeg는 priority + fetchpriority="high" |
| **사진 회전 보정** | photo_2026-05-14 08.44.55.jpeg가 거꾸로 회전되어 있음 → 별도 회전된 파일로 저장 후 사용 (또는 CSS `rotate-180`) |
| **접근성** | 모든 사진에 의미 있는 alt 텍스트, 인용 블록에 `<blockquote>` + `<cite>` 사용 |
| **공유 친화** | OG 이미지가 카톡 미리보기에 결정적 한 컷으로 노출되도록 1200×630 비율 변형본 생성 |
| **로드 성능** | LCP < 2.5s (Hero 이미지가 LCP), CLS = 0 |
